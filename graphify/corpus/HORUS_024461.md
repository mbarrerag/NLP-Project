# Color-kinematics duality from the Bern-Kosower formalism

We present a novel procedure to construct Yang-Mills Berends-Giele currents from the Bern-Kosower formalism for one-loop gluon amplitudes. The obtained currents naturally obey color-kinematics duality. As a feedback to the Bern-Kosower formalism we outline how the multiparticle fields can be used to significantly streamline the pinch procedure for the reducible one-loop amplitudes
