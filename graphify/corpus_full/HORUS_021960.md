# Classification of semiochemicals associated with coleoptera of the suborder Polyphaga by artificial neural networks.

In this research we seek to establish the relationship between the compounds mediating the interaction and the message they transmit for the coleopters of the suborder Polyphaga. To this end, we aim to develop machine learning tools to predict the response of an individual when exposed to a certain compound; that is, to establish the nature of the semiochemical according to the species to which the individual belongs and, at the same time, to look for patterns between these molecules. We construct a relational database based on the SQL language in which we store information corresponding to the taxonomic categories of insects, their hosts and the semiochemicals reported for each species; as well as, the type of semiochemical property, that is to say, whether it is pheromone (aggregation, trace, sexual, ovoposition, etc.) or alleleochemical function (cairomona, synomona or alomona); whether it presents specific attraction (macho and/o meta) and the type of semiochemical property, that is to be evaluated (field tests, electronography, electronography, ulography, ul, ulography, ul ul ul olato The combination of these tools allowed us to elucidate a first classification pattern related to their biosynthetic origin and thus classify the set of semiochemicals according to the biosynthetic routes from which they are derived. In addition, we managed to establish a model capable of assigning the type of message that a given compound transmits, that is to say the function that it fulfills for the insect-molecule pair; in other words we ascribe a function to each semiochemical depending on the insect with which it interacts
