# Construction of risk models with Python.

Recently, the use of open source tools has been popularized, these are defined as software developed with a license that allows anyone to use it freely without any restriction. The purpose of this article presents a library for risk analysis in Python programming language called PyRisk, which takes advantage of existing libraries for computing, using simulation processes to achieve the perception of the capabilities and behaviors of a scenario in which you want to study or try something, without really having to reproduce it. As a result, you get a library for scientific use, succeeding in demonstrating to be competitive with the functionalities presented by commercial tools and highlighting in features such as speed of execution and processing of large volumes of data
