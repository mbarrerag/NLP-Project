# Development of a computer program for linear analysis of three-dimensional porticated structures subjected to static loads.

For more than 50 years, the direct method of rigidities has been widely used to analyze porticated structures. In this thesis the method was implemented in the pymas library, which could be the engine of analysis of any computer program. Thus, the users of the library will only have to worry about describing the structural problem. One novelty in this implementation is the application of quaternions in the calculation of the rotation transformation matrix. Quaternions are an extension of the real numbers, similar to that of complex numbers. They were first described by the Irish mathematician William Hamilton in 1843 and have practical use in calculations involving rotations in the space. Also developed the computer program plus.js to visualize three-dimensional structures and the results of the analysis. This program uses web technologies (HTML, CSS and JavaScript), trend among the currently developers, thanks to the possibility to execute applications through the internet browser. These computer programs can import and export the model information for text files in JSON format, where the internet is stored in a convenient scheme for their reading.
