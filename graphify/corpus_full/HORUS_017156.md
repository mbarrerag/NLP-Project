# COMPUTING LIMITS USING ALGEBRAIC GEOMETRY

In this seminar we discussed the construction of an algorithm for computing limits of quotients of polynomial functions in three variables. The main ideas behind our solution is to reduce the problem to the case of two variables, which is possible using some algebraic geometry tools, and then use the algorithm constructed for the case of two variables
