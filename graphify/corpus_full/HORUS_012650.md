# Automatic composition of Experimental Protocols in Civil Engineering using AI planning

The civil engineering experimental protocols are usually managed in a manual way. The laboratory's technical personnel oversee looking, applying, and handwriting the experimental protocols. This rudimentary process hinders the reuse and adaptation of experimental information to generate new protocols. In this article, we present an architecture that allows researchers to reuse past experimental results. Different compositions of experimental protocols will result from different contexts: available tasks, material preferences, and user profiles. We implemented and discussed a problem related to the experimental protocols composition in Civil Engineering, in order to enable the buildup of new experiments departing from past ones, we propose an architecture that is based in: i) a model of experimental representation protocols to be designed as a scientific workflow, using ontologies, ii) the implementation of an artificial intelligence (IA) planning technique so that it allows automatic adaptation of previous experimental protocols, to a new user requirement, iii) composition orientation, this is achieved considering the task context, material preferences, and user profiles
