# Sliding mode control based on Washout filter for speed control in a DC engine.

The accuracy of the field engine control systems is influenced by the uncertainties and abrupt variations of load and the inherent parameters of the system [1], [2] and [3]. In order to implement a robust and easy-to-implement control method, this paper presents the application of a sliding mode control method based on a washout filter (SMC-w) for speed control in a DC permanent magnet engine. To meet this objective, the response of the control system under variations of the reference signal and changes in the load torque was studied. The results were contrasted with the conventional proportional comprehensive derivative control (PID) in order to assess the efficiency and degree of improvement of the SMC-w control against conventional control architectures and widely disseminated in the industry such as the PID control
