# ESTIMATE ESTIMATORS FOR BIOPROCESS BY USING MATLAB AND A ESP32 CARJET.

Measuring physical variables in real processes is not always easy due to the limitations that are presented in terms of ranges of variables, sensor costs, time delays, measurement noises and interferences and, currently, cyber attacks. In this sense, from the Seed of the Dynamic Process Research Group Kalman has been working for 14 years on a line of research on state estimation. Specifically, the estimation of the state of a dynamic system consists of a set of techniques that serve to reconstruct variables that cannot be measured directly, but that can be reconstructed by virtual sensors. To do this, a mathematical model of the system and a set of measurements accessible by means of the instruments that are available on the market is used. Additionally, a processor is required to implement the state estimator, which must execute its work in real time. The objective of this work is to show how this is done using an emulator of the bioprocess with Matlab® and the implementation of the estimator with an ESP32® card. The applications are made with two models of nonlinear bioprocess plants, which are the closest to the actual processes
