# Repeat path tracking control for a quadrotor.

The position control of a quadcopter allows to follow different paths independently, without the need of a pilot. When the paths to follow are repetitive it is possible to include an iterative learning control (ILC) that in each flight modifies the reference according to the error of previous attempts. The ILC algorithm is open loop so it is required to implement together with a feedback control. This feedback control must maintain performance despite the fact that the drone model is nonlinear and with high uncertainty dumbre, and that, in addition, different disturbances may appear in the flight environment. A control strategy that takes into account these problems is based on active disturbance rejection (ADRC). The estimation of total disturbance, which includes both nonlinearities and uncertainty, allows for improving the rejection of disturbances and the robustness of the system. This work shows the design and implementation of an ILC control based on ADRC, showing how performance considerably improves when compared with a traditional control
