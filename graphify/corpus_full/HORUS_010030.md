# MONITORY OF NON-LINEAL HIGH DIMENSION PROCESSING USING LEARNING PROFESSIVE

To monitor data from high-dimensional processes, several control letters based on latent variables have been proposed. ACP-based control letter to address monitoring problems with a large number of correlated variables (Aguado and Rosen, 2008; Jolliffe, 1986; Mason and Young, 2002). To address nonlinear characteristics, several nonlinear extensions of the ACP method have been presented: Kernel ACP.(Li and Yang, 2014). Then, deep learning has been applied to various control applications of this type of processes: Autoencoder (AE), Denoising Autoencoder, Sparse Autoencoder. (Daszykowski et al., 2003; Hu et al., 2017)
