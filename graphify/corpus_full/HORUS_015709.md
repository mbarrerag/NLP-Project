# Forecast failure alerts for geotechnical monitoring plans applying the reverse speed method coupled with supervised learning algorithms.

A model was developed for prediction of alert levels for geomaterial failures using the reverse method of the speed of displacement in conjunction with methods of learning of machines of supervised type, which can be used in continuous geotechnical monitoring plans. For the model, the use of VMS was proposed, and Decision Trees as methods of machine learning to be evaluated, obtaining performance results with the confusion matrix close to 0.6 in the first and 0.98 with the second. In both cases, the model training was executed with synthetic data and the evaluation was carried out using real case data where a failure of the monitored geomaterial occurred. The model demonstrates the suitability of the use of synthetic data for its training, especially for the model implemented with decision trees. However, it is clear that the model is dependent on automated geotechnical instrumentation data for the application of the continuous monitoring plan. This is necessary to be able to have a prediction system in quasi real time, in addition to the fact that it is made unquestionable that better performance is obtained when there are volumes of information of over 8 data per hour, also for the developed methodology is an essential data
