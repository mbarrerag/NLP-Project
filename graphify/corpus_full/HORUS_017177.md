# DETERMINING A MINIMUM SET OF VARIABLES FOR MACHINE LEARNING CARDIOVASCULAR EVENT PREDICTION: RESULTS FROM REFINE SPECT REGISTRY

Abstract Aims Optimal risk stratification with machine learning (ML) from myocardial perfusion imaging (MPI) includes both clinical and imaging data. While most imaging variables can be derived automatically, clinical variables require manual collection, which is time-consuming and prone to error.
