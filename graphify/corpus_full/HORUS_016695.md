# New decentralised paradigm for micronetwork operation based on active disturbance rejection control.

In this thesis we provide a data-based synthesis framework for some complex systems. The proposed framework is based on the linear operator theory involving the Koopman operator. Our first results employ the Koopman-lifted space for the identification of linear models from data, both in controlled and uncontrolled environments. Koopman’s spectral analysis and its assistant operator Perron-Frobenius helps us to identify the invariant structure and dominant modes for reduced order representation from data. Our second result is a design methodology for a decentralized control strategy and without model for interconnected systems. We provide predictive control for the decoupling of systems through the linear operator. In addition, we approach a distributed output regulation algorithm for the heterogeneous system of multiple leading-secutor type agents with an unknown leader dynamic. The leader model is learned through the Koopman algorithm and the regulator is developed using the optimal control theory. Finally, we develop a technique using the Koopman operator to obtain a continuous time optimization algorithm based on numerical data
