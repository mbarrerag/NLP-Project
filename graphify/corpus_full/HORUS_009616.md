# STUDY ABOUT A SECURITY TOOL: THE CUSUM MODEL

The CUSUM model is based on sequential monitoring of a cumulative performance measure over time. With several developments and adaptations, it has emerged as a suitable method for monitoring healthcare outcomes. This method allows identifying the number of cases in relation to individual learning variation, it uses the Cartesian plane, where the Cusum value is presented on the Y axis and the number of procedures performed on the X axis. This topic highlights a statistical method of learning based on practice, called accumulated sums or CUSUM whose importance lies in the personalized evaluation of learning
