# A hybrid focus variable selection algorithm based on mutual information for data-based industrial soft sensor applications

The development of virtual sensors that predict the desired result or product requires a careful selection of input variables for the construction of the model. In an industrial environment, data sets contain many measures of the instrumentation system; however, these variables are usually non-relevant or excessive information. This article proposes a variable selection algorithm based on mutual information examination, redundancy analysis and reduction of variables for soft sensor modeling. In the first stage, a relevance calculation is made to select important variables using the mutual information criterion. Then, the detection and exclusion of redundant variables is performed, penalizing unwanted variables. Finally, the most relevant subset of variables is determined through a wrap-up method using the Mallows Cp metric to evaluate the performance of the adjustment prediction. The approach was successfully applied to estimate ethanol concentration for a distillation column process using a diffuse inference system architecture based on adaptive network as a dynamic regression model. A comparative study was conducted considering the application of correlation analysis and the proposed method in this study. The results of the simulation show the effectiveness of the proposed soft approach to achieve the appropriate modelling models of the dynamic regression
