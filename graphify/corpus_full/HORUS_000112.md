# Analytic calculation of nuclear Fukui functions with auxiliary density perturbation theory

Analytic nuclear Fukui functions were calculated within the context of auxiliary density functional theory using an in-house implementation based on auxiliary density perturbation theory. This implementation takes advantage of the close connection to the analytic evaluation of geometric second derivatives. The implementation was validated through calculations of these reactivity descriptors for selected diatomic molecules. An application to the electrochemical decarboxylation of amino acids is presented to illustrate the benefits of this chemical descriptor and its analytic calculation
