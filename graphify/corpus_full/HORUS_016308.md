# PSEUDO HEREDITARY PROJECTIVE OBJECTS IN A SUITABLE KRULL-SCHMIDT CATEGORY

This talk is in honor and memory of Daniel Simson. We consider a Krull-Schmidt category $\mathcal{B}$ with the following properties: A.1 $\mathcal{B}$ has an exact structure with enough projectives and injectives. A.2 $\mathcal{B}$ has almost split sequences. A.3 There is an indecomposable projective object $\hat{S}\in \mathcal{B}$ such that $\mathrm{Hom}(\hat{S},X)\neq 0$ for all $X\in \mathcal{B}$ and if $f:X\rightarrow \hat{S}$ is a non zero morphism, then $f$ is a retraction. A.4 If $X\rightarrow Q$ and $Y\rightarrow Q$ are irreducible morphisms with $Q$ indecomposable projective and $X$, $Y$ indecomposable, then $X\cong Y$. We introduce pseudo hereditary projective objects to construct a suitable set of sections within the Auslander-Reiten component of the object $\hat{S}$. It should be mentioned that $\mathcal{B}$ is a generalization of a category of representations of a poset, which is non-abelian and it has been studied through different approaches.
