# Shiny application based on statistical methods supporting learning and teaching of trust

This project develops a web application for the calculation of confidence intervals through the Shiny package of the statistical software R. The application serves as a pedagogical and interactive tool, to support the teaching and learning processes of the methods for building confidence intervals, which is a prominent topic of statistical inference because of its importance for the analysis and learning of other concepts. The application shiny allows to load a data set from the local files of a computer and select a study variable with which is proceeded to calculate different confidence intervals for the respective parameter of interest, using the most representative statistical methods such as the method of the Pivot, Maximum Verosimilitude and Bootstrap, which are presented in a comparative way both numerically and graphically, and accompanied by their respective interpretations and observations on its construction. This will allow the familiarization of users with the respective assumptions behind each method and highlight when the use of each of them could be more appropriate. Although the main purpose of the application is academic use this tool can also be used for purposes more at the professional or organizational level in which it makes use of data sets and wants to have a better understanding of behavior and to give them less-than-wise-based methods of the application
