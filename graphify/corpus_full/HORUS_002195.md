# Presenting An Interactive Web Based Tool for Visualizing Cost Outcomes of Perovskite Solar Cell Recycling Methods

This project presents an interactive data visualization tool designed to support researchers, engineers, and students in exploring the economic implications of various recycling methods developed for Perovskite Solar Cells (PSCs). Designed as a single-page web application with an intuitive user interface, the tool enables users to compare and visualize the impact of different approaches used in PSC recycling on the cost of the material recovery process. The user's selections dynamically update two distinct graphs: one displaying the cost of materials and the other showing the revenue generated. The output materials resulting from each recycling choice are clearly labeled within the revenue graph, enabling users to see how each decision impacts economic outcomes. To support transparency and further exploration, the tool includes direct links to source materials. Clicking on a source name redirects users to the original publication. By combining interactivity, accessible data, and traceable references, this tool serves as an educational platform for understanding the financial trade-offs involved in PSC recycling strategies. This tool serves as both an educational resource and a decision-support system. It helps illustrate the financial outcomes of PSC recycling to encourage more informed strategies for sustainable solar technology development. With its easy-to-understand user interface and informative components, it invites a wide range of audiences to better understand the financial landscape of PSC recycling methods
