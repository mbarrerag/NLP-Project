# Design of a machine learning model for recognition and classification of pavement damage for Sogamoso roads.

This project aims to develop a machine learning model to recognize and classify damage on pavements. Computer vision and learning techniques were used, deep a pre-trained neural network (MobileNet) was used as a starting point, this approach allowed a timely implementation of the model and a reduction in the time and resources needed for its training. The performance of the model was evaluated using images captured in the municipality of Sogamoso and an acceptable result was obtained in the detection and classification of damage on pavements. The tool developed can be used for early detection of damage on roads and for decision-making in the management of road infrastructure
