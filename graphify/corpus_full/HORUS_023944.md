# ESTIMTF: R-PACK FOR THE ESTIMATION OF MULTIPLES PARAMETERS DISTRIBUTIONS OF LIKELIHOOD AND MODELS OF RETURN USING TENSORFLOW

The R programming language provides a wide variety of functions created to estimate distribution parameters and regression models using various estimation methods. The estimtf package was designed with the aim of finding the maximum likelihood estimators of distributional and regression parameters using TensorFlow, an open source library for numerical computing. To achieve this goal, the main estimtf functions implement an iterative estimation process in which the optimizers included in this library are used to maximize the likelihood function. This package provides R users with a tool that leverages TensorFlow's benefits for the solution of estimation problems and also allows to find the estimators of multiple distribution parameters and regression models that are not yet implemented in R
