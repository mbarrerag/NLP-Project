# Implementation of a prototype software to predict complications in patients in pediatric intensive care unit (UCIP), through machine learning models

Caregivers of patients in critical condition do not always have the skills or experience to treat this type of patients (Wheatc beyondley, 2006). In addition, physiological deterioration can be detected from subtle changes in vital signs within a Pediatric Intensive Care Unit (UCIP) (Izquierdo, 2021). This leads to difficulties for medical staff when making a prognosis about a future complication. According to the above, this study aims to implement a prototype software capable of predicting physiological states through vital signs, following as methodology the Automatic Learning Process (Machine Learning Process, MLP) on the selected data set. The prototype was successfully implemented and promising results were obtained in terms of the use of automatic learning techniques to represent the current and future state of patients in UCIP. Therefore, it is necessary to continue working on the effort to supplement the set of data and implement new proposals for the use of automatic learning techniques, and thus achieve constant monitoring on patients .
