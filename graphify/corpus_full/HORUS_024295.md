# Some CHARACTERISTICS OF A CRITICAL STATE MODEL FOR TROPIC STRUCTURE-SULE

The structure is not fully understood. This is evident from the large number of current proposals that show the complexity of this topic. Therefore, the effect of the structure is often not taken into account when considering the design of geotechnical structures. For this reason, it is important to develop models that are easy to implement and capable of representing this type of soil. This work shows a contribution to the concept of structure and subload (transition of the overconsolidated state to the normally consolidated state in a smooth and continuous way) in the stress-formation behavior of the soil. This was done using the Cam Clay model with subload. This model was also expanded with structured effect on the soil. In addition, an unassociated flow rule was implemented to represent the dilatation of the structured soil. Implementation was carried out under 3D conditions. Subsequently, a sensitivity analysis of the parameters of the structured soil was completed. The results show the model’s ability to represent the behavior of tropical soils with structure
