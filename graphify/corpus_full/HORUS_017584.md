# Extracting information from identity documents using machine learning techniques.

Automatic extraction of information from identity documents is a fundamental task in different digital processes such as registers, product applications, identity validation, among others. The extraction of information consists of identifying, locating, sorting and recognizing the text of key fields present in a document, in this case an identity document. In the case of identity documents, the key fields are those such as: names, surnames, document numbers, dates, among others. The problem of extracting information has traditionally been solved using algorithms based on classic OCR rules and engines. In recent years, implementations of machine learning models have been carried out, using NLP models (natural language processing) and CV (computer vision) to solve the problem in a more flexible and efficient way (Subramani et al., 2020). In this work, it was proposed to solve the problem of extracting information with an object detection approach. A model of object detection based on transformers (Carion et al., 2020) was implemented, trained and evaluated
