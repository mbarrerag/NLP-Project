# Analysis of the brain dynamics selected during coding and retention of sequential information in a work memory task

The processing of sequential information is fundamental in our ability to carry out tasks of motor or cognitive type. Of particular importance is the ability to store and manipulate this type of information for short periods of time in what is known as sequential working memory. Although studies have been carried out on this subject since cognitive psychology, there are few works in which we seek to determine the neurophysiological mechanisms that allow this type of sequential processing. The purpose of this proposal is to describe changes in the dynamics of alpha and theta oscillations during the coding and retention phases in a sequential working memory task with different demands for recovery (identity, time of item appearance, position of item in sequence) and to correlate these changes with the performance of the participants. The results of this study are expected to allow a better understanding of the cerebral rhythmic activity underlying the ability to store sequential information. It is also expected that this study will allow the development of evaluation methods that can be used as a diagnostic tool and intervention in people who have deficits in sequential work memory tasks
