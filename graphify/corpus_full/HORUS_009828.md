# APPLICATIONS OF THE THEORITY FOR THE REPRESENTATION OF ALGEBRAS IN CIVERSITY AND DATA ANALYSIS

This course will describe the use of algebra representation theory as a tool to define methods of insertion and detection of malware based on deep machine learning. As well as to establish methods of topological data analysis whose simplest example of use is the cryptanalysis of some classic cryptographic systems
