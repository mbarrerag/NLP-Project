# DATA GENERATION STRATEGIES FOR THE IMPLEMENTATION OF ADAPTIVE LEARNING ANALYTICS

In the educational field, data analytics and adaptive learning are crucial tools for improving teaching and learning. However, the lack of adequate data poses a challenge. This article focuses on designing data generation strategies for the application of adaptive learning analytics in hybrid courses, using a reverse engineering approach based on successful models. The aim is to facilitate the implementation of effective models and algorithms in education, contributing to more personalized and quality learning
