# Optimum control methodology for non-linear systems differentially flat, based on active disturbance rejection control (ADRC) and model-based predictive control (MPC).

The methodologies for model-based controller design require a high level of knowledge of the dynamic system to be able to design a control law, in contrast to the methodologies based on error; these approaches may limit the application of optimal control methodologies, since for certain situations it may be difficult to establish a model that describes the dynamic system properly, as well as, for very rigorous models there are difficulties associated with solving the optimization problem and for methodologies based on error performance is not always the desired one. As an alternative, this work proposes an optimal control methodology for differentially nonlinear flat systems, based on active disturbance rejection control (ADRC) control, which is used to estimate and reject uncertainties and disturbances (internal and external) based on a simplified model that allows for a optimization problem to be posed. Then, the controller is synthesized using the model-based predictive control methodology (MPC - by its acronym predictive control model). Through different study cases, some characteristics of the structures associated with the proposed control methodology are validated and evaluated. Finally, a control methodology is established that gives the dynamic system a robust performance function
