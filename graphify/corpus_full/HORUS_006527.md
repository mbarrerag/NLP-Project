# A Novel Nonlinear Averaged Model for a Flyback Converter with Peak Current Mode Control

In this paper, we introduce a novel nonlinear averaged model to be used in the analysis of systems with multiple components that include a flyback converter operated under peak current mode control (PCMC). Most traditional approaches often use linear models that are not suitable for capturing the transient behavior needed in applications with time scales several orders of magnitude above the switching frequency. We address these limitations by incorporating the dynamic behavior using a nonlinear model that significantly improves the accuracy of existing linear models while being general enough to be used with standard numerical integration methods. In addition to the detailed analytical derivation, both simulation and experimental validation demonstrate the efficacy of our model in a study case with an RC parallel load. The application presented promises to offer considerable benefits in terms of computational efficiency for dynamic analysis in a wide range of applications
