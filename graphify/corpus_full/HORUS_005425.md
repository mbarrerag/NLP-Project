# A COMPUTATIONAL COMPLEXITY ANALYSIS OF DISCRETIZATION METHODS TO SOLVE SEMI-INFINITE PROBLEMS

In this work, we develop a computational complexity analysis in two steps. First, we prove that the Tsoukalas-Rustem algorithm also converges in a finite number of steps when the number of constraints imposed on the SIP problem is k > 1, with k ¿ Z+. Second, we find that the worst-case scenario forces this algorithm to generate a dominant term of order k m+1.
