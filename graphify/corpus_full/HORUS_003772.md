# COMPARITIUM STUDY OF ALTERNATIVE CLASSIFICATION OF IMAGES BASED ON ANALYSIS OF FUNCTIONAL DATA.

In this work, the supervised classification of images belonging to three categories of fracture surfaces was carried out, where functional data were extracted from the images for each line of X and Y pixels. To perform the classification, algorithms based on functional data analysis (with and without the inclusion of the autocorrelation structure intra functional data) and machine learning algorithms were compared. In the classifiers using functional data, generalized linear models, distance measurements, generalized additive models and depth measurements were used. In machine learning sorters vector support machines, decision trees, random forest, perceptron neural networks, nearest K-vecinos and logistic regression were used. The best performance classifiers within machine learning algorithms were some vector support machines, the decision tree, random forest and double layer perpestrón. As a main result, the classification algorithms that used functional data, achieved levels of accuracy comparable to the best machine learning, when they involved within the models the functional data intracorrelation structure
