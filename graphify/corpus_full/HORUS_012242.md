# Intertemporal decision model for prioritizing alternatives in discrete problems considering multiple criteria.

Some problems of prioritization of alternatives should consider consequences with respect to criteria that are distributed over a time horizon. In this intertemporal context, the evaluation of alternatives with respect to the prioritization criteria becomes a set of time series that represent how the alternatives evolve. While the dynamic context can affect prioritization, traditional models recommend a decision taking as a reference the current value of each time series and the preferences of each criterion. Although this is a practical way to address a multi-criteria intertemporal decision problem, and make use of the methods already widely developed, it leaves important singularities of the temporal distribution of alternatives with respect to the criteria. To address this situation, this research proposes a multicriteria decision model that explicitly assesses the time series that describe how alternatives behave with respect to the decision criteria. This model aims to extend the priorityization in intertemporal contexts beyond the current value criterion, including attributes such as trend, variability, accumulation in time, compliance with minimum values and targets.
