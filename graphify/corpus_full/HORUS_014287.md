# Forecasts based on a multivariate self-regressive threshold model (MTAR) with multivariate t-Student error distribution from the Bayesian approach.

This paper presents a method that allows us to obtain forecasts based on an MTAR model with multivariate t-Student error distribution from the Bayesian approach. To this end, we find the Bayesian predictive distribution that includes uncertainty about the true values of the parameters of the MTAR model. The proposed procedure is based on obtaining samples of the predictive distribution to obtain the punctual prognosis and prediction intervals of the process of interest. The performance of the proposed algorithm is verified through a simulation study based on three models where the percentage of times the true values of the output process are calculated is within the 95% predictive interval of the predictive distribution. Subsequently, an application is presented to a set of financial time series where the forecasts of the returns of the Bovespa and Colcap indices are obtained using the Standard and Poor's 500 index returns as a threshold variable and the forecasts are compared with those obtained by an MTAR model with a multivariate normal error distribution
