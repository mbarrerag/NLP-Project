# Model of the Recommendation System for guided tours, based on ubiquitous and context sensitive computing

The proposed model on the one hand to function in a context of guided tours, is based on the development of the ontology tourist in Python using the library Owlready, and describes the entities of the model for guided tours. Ontology allows to apply the concepts of ubiquity and allows to represent the sensitivity to the context in three forms, with the geographic, temporal and environmental context. For the guided tour, the user profile, its preferences, the emotional state and the evaluations of the places visited, also, the profile, the itinerary and the characteristics of the site, the user's transport preferences and the characteristics of the site. A language of ontology was used to model the concepts and characteristics of the guided visits system that allows to make inferences with rules using the SWRL language with the Pellet app. For the model of recommendation, the model of collaborative filtering, focused on the user using the mean and weighted average of the site scores, and the demographic information of the user. Two models of collaborative filtering based on the analysis and using the model of the model of singular values have been developed. the guided tour, the user profile, preferences, emotional state and evaluations of the places visited are considered, as well as the profile, roaming and characteristics of the site, the user's transport preferences and the transport characteristics of the site. An ontology language was used that models the concepts and characteristics of the guide tour system that allows interference to be made with rules using the SWRL language with the Pellet Reasoner. For the recommendation of the user, collaborative filtering models have been developed, focusing on the user using the mechanical and weight measure of the consequences Allets, and the demographic information of the user
