# OPTIMIZING FILTER MAPS AND COVERINGS IN THE MAPPER ALGORITHM

In this note we describe some general ideas behind the topological data analysis, in particular, we show a way to optimize the choose of the filter map and the coverings algorithm, for this we define a poset structure on the set of coverings by intervals of R and we show that this poset can be reduced to a finite one. This is joint work with Eduardo Martínez Pedroza
