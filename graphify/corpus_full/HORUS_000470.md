# Automatic evaluation of computer programming exercises test cases

The recent growth of automatic evaluation platforms of computer programming exercises has helped teachers in the feedback of the solutions proposed by students; this is an important factor in the development of computer programming skills. However, teachers face challenges in knowing if the test cases they have created have sufficient coverage, which refers to the amount or percentage of code that is reached by the tests. The general objective of this work is to propose and develop a functional prototype of a tool that measures, automatically, the quality of a set of test cases used to evaluate the solution of computer programming exercises. The tool measures the level of coverage of these cases through metrics as branch and line coverage, providing information of its quality. The methodology employed included a review of the literature on techniques, metrics and test evaluation tools, followed by the design, implementation and validation of the prototype using a set of solutions and test cases data from 18 course exercises Introduction to the Python Program at the National University of Colombia.
