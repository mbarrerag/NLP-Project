# Generation of class diagrams and usage cases from user stories using natural language processing.

This paper seeks to develop a computational model for the generation of UML diagrams based on user stories in Spanish, through the application of grammatical patterns and natural language processing. As a data set different sets of user stories translated into Spanish and their corresponding manually generated diagrams were taken. The applied patterns were constructed based on rules established for this process in English language, which were adapted to the Spanish language and based on the extracted components, diagrams are constructed. The computational model evaluation indicates that it is able to detect components as classes and actors, reaching a recall of up to 0.8 in some cases. However, it presents precision problems when extracting their attributes, methods or cases of use, and comes to present values below 0.1 in some components. Finally, the model establishes a basis to guide designers and/or analysts in the implementation of software projects
