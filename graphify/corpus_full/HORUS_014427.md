# Design of a scalable virtual reality system to simulate the use of an industrial hybrid lathe.

For the project of deepening, a virtual reality system of an industrial hybrid lathe was implemented, supported by feedback systems with the user; seeking to generate a significant learning of this mechanical-industrial tool and in turn to reduce the accidents that can occur during the use of a real lathe. This system was developed through Unity 3D (video game engine), models in three dimensions configured for this process, programming language in scripts and animations for the user. The main function is the simulation of operations that the user has to perform when using this tool in reality, disaggregating the process of use and the possible accidents that can be generated by erring in the steps and ignoring the industrial safety standards. All this results in engineers and students who undergo simulation gaining experience in the use of the tool and strict prevention measures being a step forward compared to those who do not make use of the simulation
