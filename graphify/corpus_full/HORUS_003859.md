# Comparative study of image classification algorithms based on functional data analysis. Case study on fracture surfaces of mechanical elements

For this work photographs taken on surfaces of fracture of mechanical elements, which failed by ductile fracture, fragile fracture and fatigue fracture. Each of these types of fracture leaves a characteristic texture, from which an expert in fault analysis can use it to classify them. From the images were extracted functional data and with them the accuracy of several classification models was evaluated. From each image of 200 x 200 pixels, 400 functional data were extracted corresponding to each line of pixels in X and Y. As models were used statistical methods based on distances, generalized linear model (MLG), generalized additive model (MAG) and models based on depth measurements. Also used were models of learning machine K-vecinos furor, vector support machine (MSV), logistic regression, decision tree, random forest and neural network type of spatial classification, based on statistical models of classification accuracy, including information of spatial autocorrelation in functional data or covariate operator. LM), generalized additive model (GAM) and models based on depth measurements were used. Machine learning models such as K-nearest nearby, support vector machine (SVM), logic regression, decision tree, random forest and perceptron-type neural network were also used. In the statistical models, the effect on classification architecture of including spatial self-correction information or the covariance operator was also evaluated. As relevant conclusions, it was obtained that the inclusion of spatial autocorrelation information to classifiers based on statistical methods, improves their accessibility and that the functional data extracted from the images have sufficient information to train classifications models
