# EEG-based BCI monitoring framework: Real-time acquisition and visualization from audiovisual stimulation paradigms

The general use of neurophysiological signals to develop BCI systems certainly has various clinical and non-clinical applications.The main implementations in medical subjects include: rehabilitation, cognitive state analysis, diagnosis, communication support devices, locomotion and movement.On the other hand, there are many researches that bring BCI systems closer to healthy people in fields such as: neuroergonomy, smart homes, neuromarketing and advertising, games, education, entertainment and even security and validation.Not all EEG acquisition systems can be used in BCI systems.Even if the clinical devices are very precise tasks, these implementations have limited or non-existent access to the flow of data in real time; mainly because they are systems focused on diagnosis and analysis offline. Recently, and due to the lower than prototype development, there is in the market a set of embedded systems of high or low level, which can be from open code to EEG. To support as many devices as possible. Implementing a BCI system is an interdisciplinary activity that requires a set of specific and outstanding knowledge about communication systems, signal acquisition, instrumentation, clinical protocols, validation of experiments, software development, among others. In addition, to perform an experiment of the real world, the user must calibrate the specific set of system of acquisition, delivery of stimuli and stages of data processing. Current software approaches try to converge multiple technologies and methodologies to provide BCI systems of general purpose. The most popular is the BCI200, which incorporates default paradigms but has been pointed out that its interface is little intuitive and its functioning is difficult to understand, although it is possible to add new paradigms, this allows to include software contributions using its own libraries. and not by means of an integrated development interface. Another widely used software is OpenVIBE, this includes a graphical interface of drag and drop to perform data analysis with a wide set of predefined algorithms. Its synchronous acquisition system is known not only by freezing the computer occasionally, but also by adding delays in the transmission of signals. All these systems are able to be a broad set of devices. This environment is fully compatible with any Python module and focuses on generating real-time visualizations, data analysis and providing stimuli through network connections for remote audio-visual signaling. This approach brings together almost all the components needed for BCI research. In short, the EEG-based BCI system presented comprises the following benefits: (i) A portable and cost-effective acquisition system (hardware) based on the well-known OpenBCI devices. (ii) This approach includes a wireless communication protocol (Wi-Fi), to match EEG data acquisition and event marker synchronization of audiovisual stimulation paradigms. (iii) A system distributed within this BCI environment is implemented to carry out real-time data acquisition and visualization while promoting the inclusion of conventional or user-designed EEG data-processing libraries on a Python language environment. In addition, a method for evaluation of latency-based quality is carried out
