# On some relationships between snake graphs and Brauer configuration algebras

In this paper, suitable Brauer configuration algebras are used to give an explicit formula for the number of perfect matchings of a snake graph. Some relationships between Brauer configuration algebras with path problems as the Lindström problem are described as well
