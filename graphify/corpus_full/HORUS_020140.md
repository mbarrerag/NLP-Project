# Deep learning framework with enhanced interpretation for classification of engine image tasks

Deep learning (DL) allows multi-layered models to learn representations of data with various levels of abstraction. These methods have improved cutting-edge tasks such as voice recognition, visual object identification and many other fields. As for electroencephalographic signal analysis (EEG), especially for the Motor Imagination paradigm (MI), the availability of large data sets and advances in machine learning have led to the deployment of DL architectures, allowing understanding of the information that can contain for brain functionality. However, these models suffer some limitations in practice: i) often DL models do not properly integrate EEG spatial information with the features extracted from time-frequency, ii) the high inter- and intra-subject variability resulting, together with the small sets of data available, significantly reducing the performance of MI systems from EEG records, and iii) DL models are treated as “black boxes ” that lack physiological interpretability. In this proposal thesis, we aim to solve these problems i) by developing a melogward and ii-based learning strategy
