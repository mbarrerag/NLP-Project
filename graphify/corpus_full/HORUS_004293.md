# Graphical representation for architectural design of software with Sarch architecture description language

This final work focuses on the analysis, design and development of a tool based on the language of description of architecture Sarch, in order to facilitate the process of textual and graphic representation of the architecture of a software system. The characteristics and properties of the text representation of architectures using Sarch were thoroughly investigated, understanding its syntax and semantics to describe components, connectors and relationships in software systems. As a result, a graphical tool was created that allows architect- to design software architectures using Sarch intuitively and efficiently. The tool provides an interactive environment that facilitates the creation and editing of the textual presentation of the view of components and connectors, which generates a graphical representation with its architectural elements.
