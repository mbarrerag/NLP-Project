# Implementation of flexible lifetime distributions in regression models to estimate survival times

In the fields of reliability engineering and survival analysis, it is common to find experiments from which data characterized by non-monoton risk functions, such as bath-shaped or unimodal functions can be obtained. To model data sets such as those mentioned, flexible service life distributions are frequently proposed. However, many of these distributions are not yet implemented in statistical software to adjust regression models. In this context, we have developed the R EstimationTools package, which offers a general purpose work framework to adjust and evaluate distributive regression models. This framework uses a syntax that reflects mathematical notation. We use the maximum verisimilitude estimation and calculate the function of log-verisimilitude based on the mass/work density function implemented in the overall R work space. Our framework is particularly suitable for data sets where the response variable follows a useful life distribution, allowing users to estimate distribution parameters in relation to covariable data. s.
