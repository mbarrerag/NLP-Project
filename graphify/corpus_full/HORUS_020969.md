# Rigorous treatment of lower level problems for robust design of restricted non-linear systems

The optimal design of dynamic systems requires the formulation of an optimization problem in which the mathematical model representing the system is embedded. These mathematical models are subject to parametric uncertainty and the trajectories of the variables involved (states and inputs) are restricted by impositions that must be guaranteed during the design. Parametric uncertainty means that there are an infinite number of restrictions in the optimization problem that is to be solved for which there is a finite number of decision variables, which is known as semi-infinite problems. To solve this problem, reformulations are required that reduce the infinite character of the problem in one that can be solved with standard techniques. This is where lower level problems are proposed to carry out this reformulation and whose appropriate solution allows the solution of the semi-infinite problem to be robustly feasible. This project seeks to develop a solution algorithm for lower level problems as current implementations only guarantee the solution locally
