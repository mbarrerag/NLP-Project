# Nonlinear two-dimensional static analysis didactic program using finite element method.

This work develops the program of finite elements PEFiCA 2.3, contained within the framework of the PEFICA project, of the National University of Colombia. The development is open source and serves to solve two-dimensional static nonlinear problems with incremental schemes of external actions, considering constitutive models of plasticity J2 of Von-Mises, in flat conditions of effort and deformation. The code can execute analyses controlled by the evolution of displacements or loads and is written in language proper to the Matlab and Octave numerical computation platforms, is structured type and is associated with the GMSH graphic tool for the pre and post-process stages. The program PEFiCA 2.3 makes use of routines previously included in the PEFICA project, more specifically, in its PEFBID module, which performs analysis of two-dimensional problems before static loads and considering elastic linear materials.
