# METRIC ASSESSMENT FOR THE PERFORMANCE OF INNARAL-AMBER NETWORKS OF MOBILE ROBOTS IN THE INDUSTRY 4.0

The current mobile robotic applications in industry 4.0 require the use of a network of robots to ensure communication between different robotic agents. According to some authors, challenges are posed at robot network level as data transmission delays arise due to the large flow of information and noise that can occur. Therefore, there are different performance metrics that allow the evaluation of robot performance and robot network performance, but when evaluating a robot network it is not clear which of the different metrics to use. This article proposes an evaluation of performance metrics based on a selection of characteristics, in order to support decision-making that allows the selection of the most suitable metrics according to application. It is expected that with this solution researchers will be able to select the metrics that they require for the evaluation of robot networks within industry 4.0
