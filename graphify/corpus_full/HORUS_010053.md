# MONITORY OF NON-LINEAL PROCESS USING MACHINE LEARNING

Industrial processes have generally been successfully monitored with several methods based on latent variables using mainly Hotelling's T2 statistics. However, this statistic has weaknesses in high dimensionality. Due to technological development, some modern industrial processes generate a large amount of data, which are characterized by being nonlinear and high dimension. In this study we present some alternatives to monitor this type of processes using control cards based on the variational autocoder (VAE)
