# Calibration of NNJvt algorithm to mitigate pile-up on jets at the ATLAS experience

To mitigate the pileup in jets in the ATLAS experiment, the algorithm Neural Network Jet Vertex Tagger, abbreviated NN-JVT, is used to distinguish between hard-scatter jets (hard dispersion) and pileup jets (pileing) in order to mitigate the effects of pileup. - This work presents the calibration of the algorithm for Run 2 and Run 3 of LHC, after the calculation of efficiency scale factors and their associated uncertainties. The calculation of these scale factors was performed using events of Z (→ ee/ )+ jets since they provide clean and reliable data for calibration. These data were collected by the ATLAS detector in CERN during Run 2 and Run 3 and also the data simulated by the Monte Carlo Sherpa, Madgraph and Powheg generators were used. The cloud test was made using Z (→ ee/ ) + jets events which are also clean and reliable samples. The calibration results were successful with the uncertainty of the scale factors.
