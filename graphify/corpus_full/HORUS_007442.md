# Closing the Gap between supervisor and control theory and the real world: implementing supervisors in simulated industrial environments

The expansion of the world industry requires increasingly sophisticated and flexible automation and control systems. This work aims to address the challenge of implementing these systems by taking advantage of the Supervisory Control Theory (SCT), which offers a formal, simple and flexible method to control production plants. SCT abstracts these plants as Discrete Event Systems (DES) and model their behavior through automates activated by discrete events. By translating the models of automatas to Structured Text code according to the IEC61131 standard, this work tends a bridge between the SCT and real world applications. The implementation was tested using a Python library developed to synthesize and generate structured text code, integrating functionality of the TCT library. Three manufacturing plants of various complexity were modeled using the Factory I/O software, with synthesized supervisors for each plant and its respective structural text code implemented in the openPLC platform.
