# TEACHING BASIC LOGIC AND ARITHMETIC OPERATIONS WITH A VIRTUAL QUILT-SEWING MACHINE

There is no doubt that the technical mathematical language produces dislike and scares students whenlearning mathematics. Processes like evaluating logic expressions or arithmetic operations on positionalnumerical systems are not simple to learn due to such technical language. In this paper, we use theprogramming language of a virtual quilt-sewing machine to reduce such technical language whenteaching some elemental mathematical concepts. The programming language is a functional prolog-likeprogramming language defined with a simple syntactic structure but a powerful semantic engine thatmakes programming the virtual quilt-sewing machine a non-tedious task. It is like Prolog but uses anddefines functions instead of predicates. Machine commands are defined using commands previouslydefined and two basic commands: i) rotate a quilt/remnant (@) and ii) sew quilts/remnants of the sameheight (|). The programming environment (available on the web) draws the resulting quilt on the screen.When thinking in math concepts, it is possible to develop logic operations as quilt sewing operations ifconsidering some remnants as parenthesis, some as logic connectors, and some as truth values. Also,it is possible to use some remnants as mathematical digits (binary, quaternary, decimal, or anothernumeric base) and some others as arithmetic operation symbols to develop arithmetic operations. Wedefine all these mathematical operations without using mathematical concepts like the number or truthvalue concept. Our mathematics teaching/learning approach is a constructive one
