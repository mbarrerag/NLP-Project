# On the Kronecker problem and partially ordered sets with involution

We consider the classical Kronecker problem on two linear operators between two finite-dimensional vector spaces and we provide a new short solution using a connection between the matrix version of the Kronecker problem and the matrix problem associated to a partially ordered set with involution
