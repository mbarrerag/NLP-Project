# CHARTER OF MULTI-COVERED CONTROL FOR FUNCTIONAL AND VECTORIAL HIBRINES

A viable control graph framework is proposed for the phase 2 on-line monitoring of control processes involving multivariate functional and vector data (hybrid data) with correlation structure between them. The decomposition methodology is used in hybrid main components and a T2-based approach is presented to establish control limits. In addition, an approach is proposed that uses sensitive main components to monitor the process and eliminate subjectivity when selecting the number of main components. This framework is a useful tool for statistical quality control in complex manufacturing systems that collect data in real time
