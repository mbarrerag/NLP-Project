# Information security module, social-inspired and targeted towards integrity in MANETs within the context of the TLÖN distributed computing system.

The TLÖN system is a distributed computing system of the mobile type and with social-inspired features, which is deployed over MANETs. These are a type of wireless networks that, unlike traditional networks, are characterized by not requiring a directional infrastructure and/or route defined to operate. This ability to operate without infrastructure allows them to operate in a decentralized manner, but also allows them to execute distributed behaviors. The TLÖN approach to model these behaviors distributed from a social-inspired point of view, has been the creation of a “TLÖN state”, whose “TLÖN territory” is assimilated as a MANET, on which computational agents can be implemented acting as “TLÖN citizens” and modules with specific functions regulating interactions between these agents, acting as “TLÖN institutions”. Because generally computer systems are vulnerable in terms of computer security, this work seeks to present a “TLÖN institution” approach that can address security problems in MANNETs, particularly the integrity problems related to the TL system’s integrity
