# Recognition of biosynthetic routes for semiochemicals using machine learning techniques

In this study we considered 148 semiochemicals reported for the Scarabaeidae family, whose chemical structure was characterized using a set of 200 molecular descriptors of five different classes. The selection of the most discriminant descriptors was made with three techniques: analysis of main components, for each class of descriptors, random forests and Boruta-Shap, applied to the total number of descriptors. Although the three techniques are conceptually different, they select a similar number of descriptors of each class. We proposed a combination of machine learning techniques to look for a structural pattern in the set of semiochemicals and then to perform the classification of them. The pattern was established from the high membership of a subset of these metabolites to the groups that were obtained by a method of clustering based on diffuse logic, C-means; the pattern discovered corresponds to the biosynthetic routes by which they are obtained biologically.
