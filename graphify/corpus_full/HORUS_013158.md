# Multi-microgrid voltage control based on distributed optimization

This thesis studies the use of predictive distributed control based on the Mul-Tictors Method of Alternative Direction (ADMM) to obtain voltage regulation in interconnected microgrids. This problem is modeled by a global cost function and this work proposes an algorithm that solves it using local decisions. Likewise, the global cost function is formed by a sum of local cost functions. The global problem is solved locally using Model Based Predictive Control (MPC). Thus, the solution of the problem is obtained in a distributed way. In addition, this work presents a study of the convergence of the proposed algorithm. Ultimately, to test the proposed algorithm two simulation cases are used. First, a numerical test in MATLAB® is used in the problem of voltage regulation in interconnected micro-networks. Second, discrete devices are used to emulate the local system to be used (the functionally controlled by the Loop). and the voltage regulation problem in networked microgrids. Se-cond, discrete devices are used to emulate the networked system and individual controllers in a Hardware-in-the-Loop (HIL) fashion. Results show the effectiveness of the proposed algorithm in solving the voltage regulation problem for networked microgrids
