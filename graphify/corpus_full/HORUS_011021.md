# EVOLUTION OF THE COOL MODEL OF THE COLOMBIAN ELECTRIC SYSTEM

Abstract is presented the results of adjustment of the Colombian electric system load model, starting from the model that traditionally had the static type and presenting all the evolution to the obtaining of the model that is currently used that given the peculiarities of the load includes dynamic components.The results show the impact on the voltage of the load model and the correct performance of this model for the reproduction of the phenomenon of slow induced recovery of tension.Key words: Load model, slow induced recovery of tension, dynamic simulation. INTRODUCTION XM, as operator of the Colombian electric system, is responsible for maintaining a database in which the static and dynamic performance of the elements of the Colombian electric system is represented, in order to carry out the studies required to guarantee the reliable, safe and economic operation of the National Interconnected System (SIN) [1]. For this reason it is essential to have models that incorporate the main characteristics of the elements of the system, such as the FNC. Currently, the Colombian electrical sector has procedures for validation of models of generators, controls and FACTS devices, however, it does not have procedures for the validation of the system load model. The incorporation of new technologies with particular characteristics, such as the FNC, the current is a high-volunctability, to implement a dynamic charging model for planning studies. With regard to the above consideration, XM has defined a road map to obtain a model that allows representing the actual behavior of the electrical charge in Colombia. This route map includes the following stages: diagnosis of the current Colombian Electric System load model, review of the state of the art in load models that allows representing the phenomenon of slow recovery of voltage, request for information on the composition of the loads to the operators of the distribution network, implementation of the selected load model in the dynamic simulation tool used by XM, an initial adjustment of the parameters based on the collected information and engineering and testing criteria to verify how the new model approaches the current condition of the system.
