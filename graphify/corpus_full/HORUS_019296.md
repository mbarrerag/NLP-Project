# Estimating model of electrical demand forecast from historical data obtained from smart meters.

The following work develops a model of forecasting energy demand based on the use of data provided by smart meters. The proposed hybrid optimization algorithm for analysis was implemented by integrating tools such as Fourier series, symbolic regression and multi-objective algorithm. The results obtained are presented on a historical basis of three years. The forecast study presented was obtained from an estimating model that combines climatic variables such as pressure, cloudiness, humidity, temperature, direction and wind speed. As well as aspects such as the type of construction, type of meter, among others that contribute to a forecast to the end with the energy demand base behavior of the analyzed users. Initially, the approach of the hybrid algorithm model used to perform the energy demand forecasts will be developed, with a description of the operation of the model. Subsequently, the implementation of the algorithm is carried out in several time scenarios, implementation that is developed by having historical energy demand base data with which the algorithm tests are performed, consecutively evaluating the results obtained on the chosen training test data and code test
