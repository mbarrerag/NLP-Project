# Prototype of an automatic rating software tool with feedback process to support learning of hardware description languages.

The hardware description languages have become popular in digital electronics design due to the increasing complexity of current circuits. Due to the above, it is necessary to support the process of learning digital electronics using these languages. The main objective of this work is to develop a prototype of an automatic rating software tool with feedback process to support learning of Hardware Description Languages. To achieve this, this work presents the selection of features that should include the prototype, based on other similar tools. Subsequently, the design and implementation of a prototype was carried out that was used by students of the Digital Electronics course of the National University of Colombia for five (5) weeks. This study obtained the perceptions of its use. Students found it useful for the learning process to have an automatic rating tool with feedback, since being available online gives an advantage by not relying on a teacher or tutor
