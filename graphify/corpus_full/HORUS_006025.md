# State Estimate Based on PMUs Measures. Case Study: San Andrés Isla

This thesis work focuses on analyzing the application of the State Estimation through the Fasorial Measurement Units (PMUs) in the context of the operation of electrical networks. It identifies various applications, highlighting the comparison between the use of PMUs for the network operator and the modification of parameters. In addition, it proposes and implements a set of specific applications for the monitoring and operation of the network, addressing the identification of events and failures. The evaluation of the parameters obtained through the monitoring based on PMUs is carried out by simulations in PowerFactory to identify events, complemented by programming in Python that uses measurements of voltage in per unit (p.u.) and angles in radians. This analysis is carried out in the electrical system of San Andrés Isla, using simulated PMU measures. The approach is directed directly to the network operator of San Andrés Isla, guaranteeing robust and precise results that allow a detailed monitoring of the situation of the electrical system. .
