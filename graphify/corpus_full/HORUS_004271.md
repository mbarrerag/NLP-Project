# NEURONAL NETWORKS INFORMED BY THE PHYSICAL: KEY AND QUANTIC IMPLEMENTATION

This work will compare the classical and quantum implementation of artificial neural networks informed by physics. Depending on the architecture, different metrics of the problem that is being solved can be obtained. By using neuronal networks informed by physics the number of steps that are executed in model training increases, this is because the loss function now has information about the governing equations of the physical system to be solved. A way is then sought to accelerate the training process of the model and also obtain acceptable results. In the reference article a new type of neural networks are used which now include coupling with quantum neural networks which allow obtaining similar results in a smaller number of steps. As a particular case, in this work is considered a linear harmonic oscillator, with a 20Hz frequency and a 2Hz buffer frequency. Approximate solutions are found from the use of classical and quantum techniques, showing advantages and challenges when using the different methods of solution
