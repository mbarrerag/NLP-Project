# Analytical solution for the dynamic study of non-uniform cylindrical piles with generalized end conditions in non-homogeneous elastic soil

This work presents a simplified analytical method for the dynamic study of non-uniform cylindrical piles with generalised final conditions in non-homogenous elastic soils. The governing differential equation (EDG) of the proposed element is deduced classically using the Timoshenko approach and is resolved using the Differential Transformation Method (MDT). This complex analysis is reduced to the resolution of a system of two linear algebraic equations, whose solution is readily available and easy to encode. The proposed model represents a general solution capable of solving, with a single segment per element, the static, dynamic and stability analysis.
