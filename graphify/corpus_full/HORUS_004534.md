# Platform-independent cloud computing infrastructure definition model for scalable microservices architectures

Software systems play a fundamental role in modern day life, cloud computing has significantly expanded its scope, while reducing complexities and costs associated with its development and deployment. In this context, software architecture emerges as an essential component to ensure an optimal structure according to needs, defining innovative styles such as microservice based architectures, which are composed of a group of small highly specialized services. Considering the implementation of these systems in the cloud, the challenge arises to define the appropriate cloud computational infrastructure, especially in terms of the configuration of scalability properties, a task that is often characterized by its complexity and duration. To address this complexity, an extension of the Architecture Description Language (ADL) Sarch has been carried out, allowing the definition of scalability properties. Furthermore, rules of transformation model to model have been established that facilitate the transition from an architecture model to an infrastructure as a code, specifically configured to address the quality attribute of scalability.
