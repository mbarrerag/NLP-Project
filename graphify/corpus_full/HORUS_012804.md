# Modeling and Control Design of a Fast Capacitor Charger Using a Power Converter

This work presents the analysis and control design of a power converter to charge a capacitor for rapid energy delivery. A strategy has been implemented in which two inductors are charged in parallel using a boost like configuration while discharged using a buck configuration. The control system comprises an internal proportional current control loop and an external proportional-integral (PI) voltage control loop with compensation ramp. Once the charging condition is reached, a low-frequency control takes over the system to ensure that the capacitor always has the required charge for the final use, reducing commutations. Simulations conducted in SimulinkTM have shown a good system performance, satisfying the design requirements
