# Validation of a New Python-Based Indoor Channel Model for Visible Light Communication Using Color Shift Keying

This paper presents an experimental validation of a new Python-based indoor channel model for Visible Light Communication using Color Shift Keying. Traditional Color Shift Keying models have notable limitations, such as not accounting for the spectral response of emitters, detectors, and walls, and lacking tools for simulating Wavelength Division Multiplexing-based Visible Light Communication systems. Our model addresses these issues by incorporating spectral response and multi-wavelength propagation, designed to optimize Visible Light Communication performance in indoor environments. Validated through measurements of illuminance, color coordinates, and inter-channel interference, the model demonstrates robust accuracy, offering a valuable tool for Visible Light Communication system design and optimization
