# Some GEOMETRIES ASSOCIATED TO CONTROL SYSTEMS

Several problems applied in engineering can be modeled by means of control systems that, mathematically defined, are a system of differential equations of which there is a theory of solution and existence. Since the end of the last century, the growing development of differential geometry has been involved in applications and topics of applied mathematics, which is to be exemplified in this talk showing that types of geometries can be proposed for the study of some control systems and thus be able to have more technical and theoretical tools that can be explored in various problems
