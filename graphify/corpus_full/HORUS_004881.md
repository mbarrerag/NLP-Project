# ANALOGY AS A PEDAGOLOGICAL TOOL IN THE LEARNING OF ARCHITECTONIC COMPOSITION

The teaching process - learning in Architecture, has always travelled the paths of classical tradition. In general the same things have always been done in the same way. This presentation proposes new non-traditional options to seek better learning among students. The alternatives raised here, go hand in hand with the tool of "Analogy", which allows for a meaningful and much broader learning
