# A method for generating mental maps from a dataset of scientific articles in the context of software quality using machine learning techniques

In recent years, analysis of large volumes of text has gained relevance in various disciplines, especially with the advancement of machine learning techniques and natural language processing.In particular, research on software quality has generated a large number of scientific articles that, due to their complexity and volume, make it difficult to quickly understand and identify key ideas. One possible solution to this problem is the use of automatic tools that help to visualize the relationships between key concepts in a more accessible way. In this study, a focus to generate mental maps from a set of scientific articles related to the quality of software, using a large language model (LLM) as the main technique. The aim is to create graphical representations that allow to identify the connections and main topics in an efficient way, simplifying the understanding of the content. To achieve this objective, a review of the model was carried out to identify the best techniques of analysis of text and generation of key representations. It was decided to choose the use of a large language model (LLM) due to its outstanding ability to process large volumes of text and capture complex semantic relationships.
