# Detection of diseases in tomato leaves (Solanum lycopersicum L.) by computer vision

Tomato cultivation is a key component of global agriculture, but is significantly threatened by pests and diseases that impact performance and trade. To address this, this study investigates the application of YOLov9, a state-of-the-art object detection model, for automated disease detection on tomato leaves. Using a data set of 4,323 images with 15,135 annotations and a modified PlantVillage data set, YOLov9 models were trained and evaluated. Among the models evaluated, YOLov9e showed the highest average accuracy (mAP) with 0.964, establishing a reference point for accuracy. In contrast, the YOLov9t model provided an optimal balance for practical applications, achieving a competitive mAP of 0.95 with a rapid inference time of 8.8 ms. In addition, this work provides a public version of the PlantVillage data set with accurate and complex table-delimiter annotations, providing a valuable resource for research into object detection and extending the use of the original set of data focused on classification. The results indicate that YOLov9 models are effective in real-state detection
