# SHINY APPLICATION FOR PRACTICE GRAPHS IN CONFIDIBILITY

Probability charts are useful tools for intuitively comparing theoretical distributions with actual data distribution, as well as for evaluating the adequacy of a model for inferential processes. The aim of this work is to develop an interactive application in R Shiny that allows viewing probability graphs with fault and censorship data, functioning as proof of fit goodness. The application uses databases and SMRD package functions available in R. It is expected that students will be able to visualize the data, familiarize themselves with the availability of information in reliability analysis contexts and better understand the importance of these graphs for the selection of models
