# Predictive analytical model to make correctness in an RPA environment.

Robotic Process Automation (RPA) allows the creation of a software robot that can be programmed to perform repetitive tasks on a computer. When implementing an RPA in productive environments, the RPA can present faults or show a performance different from the expected one. For this, an analytical model is implemented that allows compliance analysis, that is, allows monitoring of RPA executions, and thus, finding failures and performing performance analyses. The first thing that is done is to make a study of the composition of an RPA, to know the programming structures and the most important operators of RPA. Then, a model is designed that allows representing and monitoring RPA executions. Next to this, an analytical model is designed, which allows to verify the compliance of the software robot, that is to compare the RPA process with RPA executions, and thus, to analyze if there are failures from RPA resources, operators or data. A model of analytics is also designed that allows to analyze the performance of the RPA, that is to be used by means of non-functional variables of the system, and thus to evaluate the RPA's performance as a case of implementation
