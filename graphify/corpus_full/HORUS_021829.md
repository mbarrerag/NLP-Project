# Implementation of a manufacturing execution system (MES) in the instrumentation, monitoring and control laboratory of the National University of Colombia.

This work implements a manufacturing execution system (MES) in the Instrumentation, Monitoring and Control Laboratory (LISC) of the National University of Colombia. This implementation shows the energy efficiency and performance of LISC laboratory flow bonds. This system is developed following the architecture of the ISA-95 standard, describing all the configurations made to the instrumentation, control, and monitoring equipment needed for the implementation of the MES application. The results of this work will serve as a reference for the Colombian industry and future work related to the design, implementation and installation of these MES manufacturing systems focused on data analysis
