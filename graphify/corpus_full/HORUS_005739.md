# DEVELOPMENT OF A HIBRED MAGNETOREOLOGIC MAGNETOREOLOGIC MAGNETOREOLOGY ASSISTANCE CONTROL OVERVIEW

This research presents a methodology for optimizing control forces in buildings, which are subjected to seismic loads. A control system called CLF-MR_1 was developed, which combines an untamed genetic classification algorithm NSGA-II and a control system based on diffuse logic. The controller was tested numerically in a real construction of 96 m height, in which 6 magnetic shock absorbers MR were installed. The structure was subjected to 8 earthquake accelerations with different frequency ranges. The input parameters for the proposed control system were the displacements and speeds of the first floor of the building and as the only output parameter, the voltage of the MR devices was defined. The efficiency of the CLF-MR_1 was compared with a second controller called CLF-MR_2, which operates through an inference system based on linguistic parameters. The results obtained indicate that the CLF-MR_1 significantly improves the dynamic response of the building, compared with the results obtained with the CLF-MR_2 and the uncontrolled condition of the building
