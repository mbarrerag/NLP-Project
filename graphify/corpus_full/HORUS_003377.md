# LOSSES AND UNCONVENTIONS OF LINGUISTIC CODE ALTERNANCE IN THE CLASSES OF FRENCH FOREIGN LANGUAGE

This communication examines the phenomenon of the alternation of language code in French Language classes at university level. In the first part, some theoretical concepts such as the mother and foreign linguistic code, the alternation of language code and the linguistic, communicative, sociocultural, psychological or organizational functions that this phenomenon performs within the classroom are taken into consideration. In the second part, the study carried out in a Colombian higher education institution is described. In this part, the perspectives of some French students regarding the phenomenon studied were compiled. Data, analyzed quantitatively, show that, often, there is a change of code when there are shortcomings in the foreign language that is learned or when they want to express certain information more spontaneity or speed. It is concluded that the use of the maternal linguistic code is useful for students, mainly at initial levels of learning
