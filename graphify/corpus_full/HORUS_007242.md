# Implementation of the material point method with dual-phase coupled formulation for geotechnical applications under static loads

The numerical modelling of problems of large deformations in Geotechnics presents several numerical challenges due to the inherent limitations of commonly used methods. These methods usually use discretization meshes under a Lagrangian formulation, which entails problems of distortion in the case of large deformations. Alternatively, they use convective terms in the material derivatives when using Eulerian formulations, which adds complexity and a high computational cost to solve the equations of movement. The developed code is based on an explicit dynamic formulation that facilitates the resolution of large deformation geotechnical problems in a flatar deformation condition under static loads, allowing for the simulation of pore pressure increase and dissipation. The implementation was carried out out in Python using open-source code and was based on an initial version of the code developed for the single-phase material MPM, known as MPM-UN.
