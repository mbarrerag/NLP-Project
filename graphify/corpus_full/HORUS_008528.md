# BACKGROUND CLASSIFICATION WITH VARIATIONAL QUANTUM FEATURE MAPS

this work, a first approximation is made to the bottleneck problem of the density matrix kernel density estimation(DMKDE) based classification algorithm when estimating the class probability of a new feature. An approach based on variationalquantum circuits is proposed for the preparation of coherent states encoding information. An ansatz is trained and its performanceon an XOR dataset is tested. Furthermore, the difficulties of this approach and its possible improvements are shown
