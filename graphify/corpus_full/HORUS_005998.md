# Control implementation for virtual synchronous generators connected to photovoltaic solar generation sources in electrical power systems

The non-conventional renewable energy sources currently represent an important contribution of the generation of electricity to the electrical power systems worldwide, the approach of integrating these alternative sources as main units of the network can lead to the instability of the systems. Considering the need for inclusions of non-conventional renewable energy sources (FERNC) to the transmission systems, the implementation of devices that have similar bearability to that of the synchronous generators is necessary, at the same time it is required that these virtual inertia injection devices have an additional system of control that is in line with the needs of the system. For the case described above, the implementation of a control system for a synchronous virtual power system (VSG) implemented in a power system through the DIgSILENT Power Factory tool, with the aim of this device injecting inertia in the network to different events, in such a way that it improves and maintains the frequency stability of the interconnective power system (VSG) is maintained, without the possibility of the possibility of the use of the system to be able to compare the system to the system. that is consistent with the needs of the system. For the case described previously, the implementation of a control system for a virtual synchronous generator (VSG) implemented in a power system using the DigsILENT Power tool is proposed, with the objective of this device inertia into the network in the event of different events., in such a way that it becomes and mains the frequency stability of the interconnected power system, mainly when there is high penetration of FERNC. At the end of the work we can show how the conservation of inertia through the VSG makes the system have a better response to load increase and decrease events, giving greater support to the system, when compared with the inclusion of solar sources
