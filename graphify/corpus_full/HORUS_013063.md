# A New Temporal Phase Shifting Algorithm for High-Stresses Zones Photoelastic Analysis

A new temporal phase-shifting algorithm has been developed for photoelastic analysis of high-stressed zones. It integrates a loading step strategy and a computational procedure for analyzing specimens with only one polariscope configuration
