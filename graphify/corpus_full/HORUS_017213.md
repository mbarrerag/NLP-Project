# Understanding and implementing deep neural networks for unconditioned generation of source code.

Code generation is a relevant problem in computer science, which supports task automation as a complete code, synthesis and translation of programs. In recent years, deep learning approaches have gained popularity in the code generation problem and some of these approaches are based on language models. However, existing studies focus mainly on evaluation using machine learning metrics. Additionally, the generation process can be classified into conditional or unconditional approaches (i.e. open-ended) according to the input context provided to the models. This research proposes CodeGenXplainer, a set of interpretability methods for unconditional source code models. CodeGenXplainer includes four methods that exploit multiple source code features, such as abstract representations, code metrics, compilation errors and token distributions. In addition, this research presents an empirical study to validate CodeGenXplainer using publicly available data and extensive sampling of code fragments.
