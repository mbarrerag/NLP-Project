# Educational program of dynamic analysis of structures with rigid and flexible diaphragms.

To study the behavior of a reticular structure under variable actions over time, computer programs based on matrix and dynamic analysis of structures are required, which simulate properly rigid, semi rigid and flexible diaphragms. To this end, the National University of Colombia began since 2014 the UNDEN project, in which open source programs have been developed for academic and research purposes. In this final mastery work an open source computer program was built capable of doing dynamic modal chronological analysis and dynamic spectral analysis in reticular structures with rigid, semi rigid and flexible diaphragms. This program, called UNDIN2.0, was written in the MATLAB and OCTAVE languages. In the simulation of a structure with this program, first it built its graphically model, using the preprocess environment of the GMSH tool. Subsequently, UNDIN2.0 read these input data, analyze the structure and write the results. The latter are graphically represented by the post-process environment of this tool.
