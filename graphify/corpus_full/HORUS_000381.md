# A persistent homology gait analysis for Parkinson disease characterization

Parkinson's disease (PD) is a long-term degenerative disorder of the central nervous system, that primarily affects the execution of voluntary movements. The diagnosis and treatment of PD is usually based on gait analysis, which exhibits, for a control population, complex synchronized motions with a semi-periodic behavior. For Parkinson patients, gait is altered showing motion slowness, rigidity and lost of periodicity during the execution of locomotion. From a persistent homology analysis, a markerless PD characterization allows to discriminate Parkinson population, following topological index features related to predictability and periodicity of gait. For doing so, a set of motion trajectories are obtained from gait video sequences, representing main joint postural configurations. Each of these trajectories are characterized and coded according to the periodicity level, following a Sliding Windows and 1-Persistence Scoring (SW1PerS). The resulting points from each trajectory are mapped to a common space that allows persistent homology analysis. From such topological space, it was possible to compute indexes that describe locomotor periodicity, discriminating between Parkinson and control population. This methodology was evaluated in a set of 22 people (11 PD patients and 11 control subjects). The topological index with the highest discrimination capacity between the two subjects groups is the one based on periodicity with the SW1PerS method. These results indicate that Parkinson's patients and controls have statistically significant differences with respect to the defined periodicity gait patterns
