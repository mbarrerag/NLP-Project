# Quantum classification strategy based on the Spin Paradigm

Recently, quantum computing (QC) has demonstrated advantages in the speed of processing information compared to classical computing. These advantages are due to the fact that QC allows processing information using overlap and interlinking, specific phenomena of the quantum regime. A sub-disciplinary area of QC that competes with its classic counterpart, showing better results in data processing, is quantum machine learning (QML). This subtype allows performing machine learning (ML) tasks using quantum processors (QP), which improves the speed and results compared to the classic ML.
