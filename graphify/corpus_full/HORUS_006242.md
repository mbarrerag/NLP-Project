# Application of machine learning techniques to video file analysis for crime detection

This thesis focuses on the development of an application for citizen security using machine learning techniques, with the main objective of detecting crimes through video file analysis. The research begins with a systematic review of the most relevant techniques, establishing selection criteria that prioritize structures capable of efficiently integrating the temporal dimension. Machine learning models are favoured, which offer versatility for incorporating new parameters, especially those based on spatial-temporal schemes, fundamental for video analysis and consideration of the temporal context of events. Since the collection of extensive and tagged data is unviable in the temporary framework of the project, it is chosen to use simulations based on public data sets in line specifically designed for crime detection. At least one type of crime is selected for research, considering its relevance and availability of repetitions for the effective development of the prediction model. The validation of the model is carried out by means of a comprehensive evaluation, using various sets of previously selected data and key performance parameters, such as the ROC - AUC curve.
